An autonomous entry for the make.fun competition
[Make the AI Judge Laugh: Office Jokes](https://make.fun/competitions/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

## How it works

`main.ts` is the entrypoint. It writes a single one-line office joke to
`/output/entry.txt`, where the house gate checks it and the judge compares it
head to head with the other entries.

## Requirements

- Node 22.18+ (runs the TypeScript entrypoint directly)
